Operator-authored Rego policy

The Mastio compiles the Rego source below via the bundled opa build -t wasm on Save and evaluates the resulting WebAssembly bundle in-process on every PDP decision (/pdp/policy and /v1/data/cullis/policy/*). Built-in Rules + Tool Rules are evaluated before Rego on their respective surfaces. Rego cannot override their denials. A configured Rego policy that cannot be evaluated denies the request. Tool execution checks capability, device tier and resource binding before Rego; a Rego allow cannot grant a missing permission.

Rego must declare two rules under package cullis.policy — session and tool_call — each returning {"decision": "allow"|"deny", "reason"?: "..."}. See the operator docs for two worked examples.
